House Control

Личное приложение для macOS: 3D-модель квартиры в выемке экрана для управления умным домом и просмотра архива домашней камеры. Приложение не распространяется публично и используется только его автором.

Google Drive используется только для хранения и воспроизведения записей камеры, которые создаёт само приложение.
